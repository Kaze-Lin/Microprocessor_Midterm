# 微算機期中複習

精簡整理指定的 Lecture 0–6 與 Lab 0–6，以圖解、分級練習與章末自我檢查串起概念。

## 開啟網站

直接雙擊 `index.html`，免安裝、離線可用。若需本機預覽，在此目錄執行：

```sh
npm start
```

以 Node.js 啟動後開啟 <http://127.0.0.1:4173/Midterm_Review/>，按 `Ctrl+C` 結束。連接埠可用 `PORT=4174 npm start` 覆寫；不需安裝 npm 套件。

來源 PDF 保留在本目錄的父目錄，並維持原有檔名與子資料夾路徑，才能由來源連結回查。網站本身不依賴網路服務。

## 複習方式

- 側邊欄可主動收合；依章節閱讀重點與圖解。
- 每小節附 2–5 題練習；章末提供自我檢查。答案預設關閉，點選後才顯示。
- 已讀進度與檢查勾選存在目前瀏覽器的 `localStorage`；更換瀏覽器、開啟方式或清除網站資料，狀態可能不同。

| 指標 | 1 級 | 2 級 | 3 級 |
| --- | --- | --- | --- |
| 難度 | 辨識 | 應用 | 整合 |
| 重要性 | 補充 | 常用 | 核心 |
| 後續關聯 | 延伸 | 支援 | 先備 |

內容依講義使用的實驗環境整理；實際工具版本、板型與接腳設定應配合課堂環境。重要性與分級是複習建議，題目依教材自編，並非官方出題預測；考試範圍以教師公告為準。

## 更新內容

編輯 `content/ch*.json` 後執行：

```sh
npm run build
npm run check
```

`build` 重新產生供離線頁面讀取的 `content.js`；`check` 檢查 JavaScript 語法、內容結構、分級、題數與來源連結。請勿直接修改自動產生的 `content.js`。

本目錄使用獨立 Git 儲存庫記錄版本，不需要遠端。可用 `git status` 查看修改、`git log --oneline` 查看紀錄，更新後以 `git add` 與 `git commit` 保留版本。
